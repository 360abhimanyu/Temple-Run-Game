JUNGLE DASH — ENDLESS RUNNER

Files
- index.html: game layout
- style.css: styling and responsive layout
- script.js: canvas drawing, movement, obstacles, coins, score and game logic

How to run
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Click Start running.

Controls
- Left / Right arrows (or A / D): change lanes
- Up arrow / Space: jump
- Down arrow (or S): slide
- P: pause/resume
- On mobile: use the on-screen buttons or swipe on the game area

Notes
- The game is made with plain HTML, CSS and JavaScript. No build tools or libraries are required.
- Best score is saved in localStorage in the browser.
- Google Fonts is optional; if offline, the page uses a system font.
